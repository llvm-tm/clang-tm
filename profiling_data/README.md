# Profiling Data (Git-Ignored)

Raw TSX profiling output generated by `patches/profile/tsx/run_tsx_profiling.py`.

## Directory layout

```
profiling_data/
  raw/                  — CSVs with per-benchmark TSX_STATS
  calibration/          — Aggregated calibration JSONs
```

## Contents

- **`raw/tsx_profile_{timestamp}.csv`**: one row per (backend, benchmark, thread-count) run.
  Columns: backend, benchmark, variant, threads, wall_time_s, and parsed TSX_STATS values
  (xbegin_ok_cycles, xend_cycles, read_cycles, write_cycles, etc.).

- **`calibration/calibration_{timestamp}.json`**: per-benchmark calibration records,
  weighted by transaction count across variants.

## What goes in `machine_profiles/` instead

The `machine_profiles/` directory (tracked in git) contains the *refined* machine
profile after reviewing calibration data.  The raw data here is experimental and
may contain noise — do not commit it.
