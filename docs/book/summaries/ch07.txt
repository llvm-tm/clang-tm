PURPOSE: Rebuilds the database isolation-level tradition in the book's
history vocabulary, quantifies what each rung costs in aborts, and argues
the chapter's thesis (the "cliff argument"): everything below serializability
is unsound in shared memory because the TM observer is inside the address
space; what transfers from the weak levels is their machinery (MVCC, early
lock release, snapshot batching, static scheduling), not their promises.

SECTIONS
- The Shape of the Space: Dimensions of Transaction Semantics
    Table of eight dimensions (visibility, strictness, ordering, anomalies,
    crash-awareness, recoverability, progress, durability) with database vs
    TM ranges; one structural cause: protocol-boundary observer vs in-process
    observer. Taxonomic lineage: Gray strictness, Berenson anomaly critique,
    Adya containment, Kleppmann engineering.
- The Isolation Ladder
    RU/RC/RR/SI/SSI/S(+strict) restated as read-from constraints; containment
    reading (Adya); which rungs are implementable in TM (top only).
- Anomalies: The Matrix and Its Witnesses
    Berenson matrix (dirty read, non-repeatable, phantom, lost update, write
    skew) x levels, each cell witnessed as a history; anti-dependency
    characterization stated (applied depth: no proof); methodology lesson:
    define guarantees by demonstrable anomalies.
- The Price Each Rung Buys
    Derives p_abort from validation scope: SI checks w object-chances per
    contender, serializable OCC 2r+w; geometric-attempts model continues
    sec:math-example; table + tikz curve (k=50, r=4, w=1); tool
    docs/book/tools/iso-cost.py; caveats (independence approx, 2PL waits,
    SSI cycle tax).
- From Mechanism to Semantics and Back
    Mechanism knobs vs promises: version management, write-back/through +
    TinySTM WBCTL/WBETL/WT, early lock release (EAGER_BROKEN = EAR without
    version check), eager/lazy detection, static transactions (Calvin, SGL),
    GPU snapshot thresholds; table sem-mech maps systems x promises.
- The Half That Cannot Cross Over
    Cliff argument, five observations (boundary-is-the-guarantee; pointer
    applications cannot reconcile anomalies; the no-wait prize is already
    paid; predicates don't exist over memory; recoverability collapses).
    Quotable line: isolation levels promise about answers to clients, TM
    conditions about state peers act on.
- Worked Example: Write Skew, Checked
    Doctor/bank write-skew history (lst:banksi-history); docs/proofs/
    BankSI.tla with SERIALIZABLE=FALSE/TRUE configs; make check-teaching;
    history notation = anomaly matrix = TLC verdict, three ways.
- Summary
- Exercises
    6 tagged: history constructions (RC<RR<SI), general write-skew cycle,
    sandbox EagerBroken, SSI config in BankSI.tla, cost-table recomputation
    vs bank simulator, Berenson cursor reading.
