- Store Buffers and Memory Ordering
    Store buffer; memory consistency models defined via litmus tests.
  * Sequential Consistency
    Lamport's SC; one global order; no anomalies; no commercial SC machine.
  * Total Store Order (x86-64, SPARC)

    All four pairs relaxable; barriers (dmb, sync/lwsync/isync),
    ldar/stlr, dependencies; message-passing litmus anomaly diagram;
    IRIW; POWER8 HTM backend tie-in (backends/tm_impl/power8_htm).
  * Other Models and the C/C++ Contract
    RISC-V RVWMO cousin; GPU scopes (Ch.17); C11/C++11 atomics as the
    portable contract; litmus summary table (SB/MP/IRIW x TSO/ARM-POWER).
