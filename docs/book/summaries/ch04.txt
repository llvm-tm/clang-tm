PURPOSE: Language side of the TM boundary: how C/C++/Rust express the memory
model, ABI hazards, volatile/inline-asm/atomics, and how TM annotations
integrate into a language.

SECTIONS
- C/C++ Memory Model and ABI Hazards: volatile, Inline Assembly, and Atomics
    Data-race UB, compiler reorderings, barrier semantics, DATA/TEXT symbol
    pitfalls, sigsetjmp hazards.
- Language Integration Case Studies
    Intro contrasts ruling-things-out (Rust) vs rewriting (annotations).
  * Rust: The Borrow Checker and TM
    Send/Sync, ownership vs shared-memory TM, UnsafeCell; safe Rust bank
    transfer with the companion tm crate (TmCell/transaction, no unsafe in
    client code); what the type system proves vs what the runtime owes.
    NEW para: abort via TmxAbort panic payload + catch_unwind (Drop runs;
    longjmp unsound in Rust) explains the closure-shaped API; ref app08.
  * Language-Integrated Annotations for TM
    transaction_safe, atomic blocks, [[tm::shared]] style annotations.
  * Haskell: The Pure Escape Hatch (NEW)
    GHC STM monad: TVars only path to shared mutable state, retry/orElse
    (lst:haskell-stm), crash class inexpressible not prevented; retry =
    read set as wait set; STM monad composition; GHC impl = optimistic
    multi-version + global commit lock (NOrec-like); unsafePerformIO =
    boundary breach.
  * Clojure: References, not Cells (NEW)
    refs -> immutable values, dosync/alter/commute/sync+refset-of/io!
    (lst:clojure-stm); placed at SI on Ch.7 ladder (write skew admitted);
    values as snapshots; io! = enforced privatization discipline; commute =
    programmer-facing validation dial.
  * Scala and Python: Library STM Where the VM Removed the Excuse (NEW)
    scala.concurrent.stm Ref/atomic/orRetry + transformer API; pySTM exists
    for the no-GIL dialects (Jython/IronPython/PyPy STM experiment): STM
    appears where shared mutable state becomes real.
  * The Negative Space: JavaScript, PHP, and Kotlin (NEW)
    No STM because the three preconditions (shared memory + in-place mutation
    + need) are designed away: event loops/message passing (JS, PHP),
    coroutines/channels confinement (Kotlin). STM = shared-mutable-state
    technology.
