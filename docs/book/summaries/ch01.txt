PURPOSE: Introduce the core problem of concurrent memory access and present
transactional memory as a solution. The bank transfer example is introduced
as the running example throughout the book.

SECTIONS
- The Concurrency Problem
    Data races, critical sections, lock-based programming drawbacks.
- Transactional Memory Overview
    Transaction concept, ACID properties, hardware vs software TM.
- The Bank Transfer Example
    Shared state, atomic transfer, the running example.
- TM API Design
    tm_begin, tm_end, tm_read, tm_write, tm_commit, tm_abort.
- Correctness Conditions
    Strict serializability, opacity, progress conditions.
- Hardware Transactional Memory
    RTM (Haswell+, Ivy Bridge), XABORT, HLE, TSX fundamentals.
- Taxonomy of TM Systems
    Optimistic vs conservative, single-version vs multi-version,
    thread-level speculation vs word-level tracking.
