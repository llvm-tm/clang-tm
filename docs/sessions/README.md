# Long-session notes

One file per substantial session: `YYYY-MM-DD.md` (e.g. `2026-09-05.md`).

Use this instead of bloating `AGENTS.md` when a session's notes are longer than a
few lines. Keep a **one-line** `## Session YYYY-MM-DD — <title>` pointer in
[`../../CHANGELOG.md`](../../CHANGELOG.md) that links here.

Suggested structure:

```md
# Session YYYY-MM-DD — <title>

## Goal
## What changed (files)
## Verification (commands + results)
## Follow-ups (link TODO.md entries)
```
