# Notes
# - Free-running (no per-iteration barrier) with one outer barrier.
# - Transactions are intentionally short (1 access + xend); abort rate
#   reflects conflict semantics, not time-out.  A 2000-pause TX aborts ~100%
#   on this hardware due to timer-interrupt / capacity time-out.
# - Per-iteration barrier or handshake *inside* TX yields 100% false aborts
#   (the handshake line itself conflicts); time-based stagger inside TX also
#   over-constrains and aborts.  Verified by running both variants.
# - Pinning to different physical cores is required; unpinned or same-core
#   siblings give ~50% higher abort rates due to migration and L1 sharing.
# - WW shows ~0.1% aborts for a 1-access TX because the overlap window is
#   tiny; a 4-access bank transfer shows ~40-60% aborts (see tsx_contention
#   runs in the same session).
